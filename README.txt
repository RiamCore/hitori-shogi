ひとり将棋：音量設定・効果音・音声案内追加版

変更点
- 縦長スマートフォンでは盤面の高さも利用し、横幅だけでなく縦方向にも広げます。
- 人間とCPUの両方が駒を動かすたび、駒を置く「パチッ」という短い音が鳴ります。
- 成ったときはチャイムと「成り」の音声案内、王手のときは別のチャイムと「王手」の音声案内を追加しました。
- メニューに音量設定を追加しました。駒音・チャイムは0〜200%、音声案内は0〜100%で調整でき、設定は端末内に保存されます。
- 音量設定には動作確認用の「駒音を試す」「音声を試す」ボタンがあります。
- 効果音はWeb Audioで生成するため、追加の音声ファイルや通信は不要です。
- 既存の将棋エンジン、持ち駒表示、待った機能は維持しています。
- サービスワーカーのキャッシュ名を更新し、修正版が読み込まれるようにしました。

GitHub Pagesへの反映
1. ZIPを展開します。
2. 中のファイル一式を既存のひとり将棋リポジトリのルートにアップロードし、同名ファイルを置き換えます。
3. engineフォルダも含め、フォルダ構成を維持してください。
4. Commit changesで保存します。
5. iPhoneのSafariでページをオンライン状態で開き直し、更新を確認します。

注意
- 実機での見た目はiPhoneの表示倍率やSafari/ホーム画面アプリの状態によって異なります。
- 盤面のマスを縦長にする調整です。将棋盤の各マスを正方形に保つ変更ではありません。

音声について
- 音声案内はiOSの音声合成を使います。iOS側の仕様上、100%を超える音声増幅はできないため、読み上げ音量は本体の音量ボタンでも調整してください。
- iPhoneの消音スイッチや音量設定によって聞こえ方が変わる場合があります。
- 「成り」「王手」の読み上げは端末の日本語音声機能を利用します。読み上げが利用できない場合も、識別用のチャイムは鳴ります。
