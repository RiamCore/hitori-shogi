ひとり将棋（待った機能修正版）

【今回の変更】
・CPUが応手した後に「待った」を押すと、自分の直前の手とCPUの応手を両方戻し、もう一度指せるようにしました。
・自分の手で対局が終了し、CPUがまだ指していない場合は、その手だけを戻します。
・iPhoneのホーム画面アプリにも更新が反映されるよう、オフラインキャッシュのバージョンを更新しました。

【GitHub Pagesへの反映】
1. ZIPを展開します。
2. GitHubの RiamCore/hitori-shogi リポジトリで app.js と sw.js を新しい内容に置き換えます。
3. Commit changes で保存します。
4. Wi-Fi接続中にSafariで https://riamcore.github.io/hitori-shogi/ を開き、更新を読み込ませてからホーム画面のアイコンで確認します。

このアプリは試作版です。将棋ルール全般の完全な検証を保証するものではありません。
