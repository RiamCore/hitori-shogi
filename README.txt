ひとり将棋：縦長画面向け盤面調整版

変更点
- 縦長スマートフォンでは盤面の高さも利用し、横幅だけでなく縦方向にも広げます。
- 盤面の各マスは縦長になります。画面全体に合わせて見やすくするための調整です。
- 既存の将棋エンジン、持ち駒表示、待った機能は維持しています。
- サービスワーカーのキャッシュ名をv4に変更しました。

GitHub Pagesへの反映
1. ZIPを展開します。
2. 中のファイル一式を既存のひとり将棋リポジトリのルートにアップロードし、同名ファイルを置き換えます。
3. engineフォルダも含め、フォルダ構成を維持してください。
4. Commit changesで保存します。
5. iPhoneのSafariでページをオンライン状態で開き直し、更新を確認します。

注意
- 実機での見た目はiPhoneの表示倍率やSafari/ホーム画面アプリの状態によって異なります。
- 盤面のマスを縦長にする調整です。将棋盤の各マスを正方形に保つ変更ではありません。
