ひとり将棋（メニュー画面・盤面レイアウト修正版）

【今回の変更】
・起動するとメニュー画面が表示され、CPUの強さを選んでから「対局開始」を押します。
・対局中は設定項目を隠し、盤面と対局に必要な操作を中心に表示します。
・盤面の縦横ともに9マスを均等なサイズで固定し、駒の有無でマス目の大きさが変わらないようにしました。
・オフライン用キャッシュのバージョンを更新しました。

【GitHub Pagesに反映する方法】
1. PCでGitHubの RiamCore/hitori-shogi リポジトリを開きます。
2. index.html、style.css、app.js、sw.js の4ファイルを、それぞれ新しい内容に置き換えてください。
3. ファイルの編集画面で変更を保存（Commit changes）します。
4. 1～2分ほど待って、https://riamcore.github.io/hitori-shogi/ を開いて確認します。

【iPhoneで確認するとき】
・ホーム画面に追加したアイコンから起動し、メニュー画面が出るか確認します。
・新しい表示に切り替わらない場合は、Wi-Fi接続中にSafariでサイトを開き直して少し待ってから、ホーム画面のアプリを再起動してください。
・更新を確認するまでは、オフラインテストをしないでください。

このアプリはオフライン動作を想定した試作版です。将棋ルール全般の完全な検証を保証するものではありません。
