ひとり将棋・やねうら王エンジン テスト版

このZIPは、現在の「ひとり将棋」にやねうら王 + 水匠PetiteのWebAssembly版を組み込むためのテスト版です。
まだ実機でのエンジン起動を確認していないため、エンジンを起動できない環境では簡易CPUに自動で切り替わります。

ファイル:
- index.html / style.css / app.js / sw.js / manifest.json
- engine/nosimd/ 配下: やねうら王WebAssemblyエンジン

GitHub Pagesへの反映:
1. ZIPを展開する。
2. 中身のファイルとengineフォルダを、hitori-shogiリポジトリのルートにアップロードする。
3. 既存ファイルは同名ファイルを置き換える。
4. Commit changesで保存する。
5. 公開後、iPhoneのSafariでページを開き直す。サービスワーカーの更新後、ページをもう一度再読み込みする。
6. 対局開始後、ステータスに「やねうら王」と表示されればエンジン使用中。「簡易CPU」と表示された場合はエンジンを起動できていない。
7. エンジン使用中になったらWi-Fiを切り、対局できるか確認する。

注意:
- このテスト版はGitHub Pages上でCOOP/COEPヘッダーをサービスワーカーから付加する方法を試します。iOS Safari / ホーム画面アプリでの動作は未確認です。
- エンジンの思考だけを置き換えています。画面側の合法手判定・全ルールが完全にエンジンへ置き換わったわけではありません。
- GPLv3ライセンス条件が適用されるソフトウェアを含みます。配布する場合はライセンス文と対応ソースコードの公開条件を確認してください。
