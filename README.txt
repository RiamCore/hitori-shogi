ひとり将棋（iPhone 8向け・オフラインPWA試作版）

内容
- index.html / style.css / app.js：アプリ本体
- manifest.json：ホーム画面起動用設定
- sw.js：オフライン用キャッシュ

重要
iPhoneのホーム画面に追加し、オフラインで起動するには、最初の一度だけHTTPS対応のWebホスティング先で開く必要があります。
その初回アクセス時にファイルをキャッシュさせてください。以後はオフラインでの起動を想定しています。
HTMLファイルを「ファイル」アプリから開くだけでは、ホーム画面アプリとしての動作やService Workerによる保存は保証されません。

使い方
1. ホスティング先へこのフォルダ内のファイルをすべて配置する。
2. iPhoneのSafariで index.html のページを開き、読み込みが完了するまで待つ。
3. 共有ボタン →「ホーム画面に追加」。
4. 追加したアイコンから起動し、Wi-Fiを切っても起動・対局できることを確認する。

操作
- 自分の駒をタップ → 移動先をタップ
- 持ち駒を打つ場合は、持ち駒をタップ → 盤上の移動先をタップ
- 「待った」は直前の手を戻す（CPUの返答後は自分とCPUの手を戻す想定）
- 難易度は1〜3。iPhone 8での応答速度は実機で確認してください。

試作版の注意
これは外部ライブラリを使わない、通信不要の試作です。将棋の全ルール・CPU強度・端末性能を十分に検証した完成品ではありません。特に長い読みの強さ、千日手、入玉宣言法などは未実装です。実際に対局し、合法手や詰み判定に不具合があれば修正が必要です。
